# Параллельная обработка изображений

Программа размывает картинку, применяет медианный фильтр и выделяет границы.
Сравнивает время последовательной и параллельной обработки.

## Запуск в Windows

Открой командную строку (cmd) в папке проекта.

Создай виртуальное окружение и активируй его:

```bat
python -m venv .venv
.venv\Scripts\activate.bat
```

Установи зависимости и запусти программу:

```bat
python -m pip install -r requirements.txt
python main.py
```

При следующих запусках достаточно активировать окружение и выполнить
`python main.py`. Окружение создаётся на каждом компьютере отдельно.

## Выбор картинки

По умолчанию обрабатывается `example.png`.
Для своей картинки положи файл рядом с `main.py` и измени в начале кода:

```python
IMAGE_FILENAME = "photo.jpg"
```

Результаты сохраняются в `output`: четыре картинки и файл `comparison.txt`
со временем выполнения. При следующем запуске они перезаписываются.
